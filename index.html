How it works
  1. Add everyone's name, and group people who shouldn't draw each other into a household.
  2. Share this page (Share button on claude.ai) so relatives can open it, then paste that link above.
  3. Press Draw names and send each person their own message.
  4. Each person opens their link (or pastes their code below) and sees only who they're buying for.
